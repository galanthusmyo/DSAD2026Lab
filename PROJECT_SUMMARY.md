Run a lab script with Python and its listed imports installed. Matplotlib is configured to use the `TkAgg` backend in `/home/myo/.config/matplotlib/matplotlibrc` so `plt.show()` opens a window in the local desktop session.
The local `.venv` uses system site packages for the Lab 4 Python dependencies.
