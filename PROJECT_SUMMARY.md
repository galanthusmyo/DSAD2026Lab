# Project Summary

Last reviewed: 2026-11-17

## Purpose

Python exercises for data analysis and statistics, organized by laboratory.

## Key files and operation

- `Lab8/main.py` demonstrates linear discriminant analysis on Iris.
- `Lab8/main2.py` analyzes `Lab8/hernia.csv`, produces class summaries and LDA results as CSV files in the current working directory, and displays plots. Run with `.venv/bin/python Lab8/main2.py` from the repository root.
- `Lab7/individual.py` performs factor analysis on `Lab7/test.csv`.

The local `.venv` contains the Python packages used by the exercises. Plot display depends on a working Matplotlib graphical backend.
